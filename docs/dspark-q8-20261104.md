# Q8_0 DSpark draft measurement

2026-11-04, Apple M5 Pro, macOS, CPU only. The Q8_0 draft is generated and validated. This run measures the new candidate and reuses the existing mixed-draft records; it does not rerun the mixed or ordinary-generation baselines.

## Model

`Spark-X2.6-4B-DSpark-Q8_0-backbone.gguf` contains 37 Q8_0, seven BF16 and 14 F32 tensors. All five layers' FFN gate/up/down and Q/K/V use Q8_0, along with attention output, FC and Markov W2. Attention gates, Markov W1 and confidence projection retain BF16; F32 values remain unchanged. The shared main-model head retains Q8_0.

The model is 700,596,512 bytes (700.6 MB), versus 486,293,792 bytes (486.3 MB) for the mixed draft: +44.1%. It was quantized directly from the original BF16 model, with no importance matrix. Tensor names, padded shapes, retained data and metadata were validated; only `general.file_type` changed among original metadata keys. SHA256: `360bb19f510d7be4171fc4de3657b1000f85f2cf081da37425e67f181b88fd66`.

Recipe: [dspark-q8-backbone-tensor-types.txt](dspark-q8-backbone-tensor-types.txt). Build and model selection: [dspark-cpu.md](dspark-cpu.md).

## Protocol and limits

- Three independent Q8 processes, each with a separate 24-token warmup and three repetitions of each prompt: 27 formal requests, 2592 actual output tokens. A separate two-repeat, 24-token smoke check for each prompt is excluded. EOS can end output before the 96-token budget.
- Main model Q4_K_M and the integrated `cpu_opt` source after `7a9121b511b6be28f0c6ac35334f9ca45fd1efad`; target and draft use eight CPU threads, F16 KV and FA on. Batch/ubatch 512, context capacity 2048, initial history zero, single slot, cache_prompt false. Actual input tokens are recorded per request. Greedy temperature 0, seed 1234, draft maximum 7, p_min 0.
- Generation throughput is `sum(predicted_n-1)*1000/sum(predicted_ms)`, including draft, verification, sampling and scheduling, excluding load and prefill. Request wall time includes prefill; nonstreaming does not provide TTFT. Draft timings are per-request differences of cumulative duration/call counters after excluding warmup. Other generation time is not labeled as pure main-model verification.
- Q8 process aggregate throughput: 39.810, 40.181, 40.402 token/s; first-to-last change +1.49%. No baseline process was repeated, so baseline drift is unavailable.
- AC power, owned caffeinate and an exclusive shared measurement lock. The run waited for an independent MLX benchmark to release that lock. Background snapshots and loaded-library logs are retained; desktop load and unpinned clocks limit generalization. No Windows or long-context result is established.
- An initial queued runner was stopped before starting a model, to allow early EOS in output-length validation; its [record](../build-dspark-cpu/q8-draft-20261104/measurement-queued-v1/ABORTED.json) is retained. Only the completed run above contributes samples.
